# Security & privacy

Report suspected vulnerabilities privately through GitHub's **Report a vulnerability** feature when enabled, or contact the maintainer directly. Avoid posting exploit or private user data in public issues.

The base Windows app does not read prompts, record keystrokes, inspect browser DOM, or upload user settings. The **optional** Chrome companion does inject an explicitly installed content script on ChatGPT, Claude and Grok pages, but that script checks Stop-button attributes only. It does not intentionally read messages, prompts, replies, cookies, history or traffic; it sends only an allowed provider/state pair through Chrome native messaging and a current-user Windows named pipe. Live compatibility and permission/privacy review are still in beta. Preferences are stored locally in `%APPDATA%\Sidelane\settings.json`; scratchpad tasks and manually entered AI status labels are kept only in RAM.

Configured shortcut URLs are only launched on explicit click and are restricted to HTTP/HTTPS without embedded credentials. Windows media information comes from the system media-session interface. Sidelane contacts `api.github.com` once per day to check for new stable releases; any update installation requires explicit approval and a SHA256 match against the official GitHub release. Both Windows app and setup are unsigned; Windows SmartScreen may warn. Install the browser companion only from the source you trust and verify its requested site permissions.
